# API and JSON Project

## Project Description

This project demonstrates how to work with APIs and JSON data using Python.

## Technologies Used

* Python
* API
* JSON
* Requests library

## Features

* Send requests to an API
* Receive data from an API
* Process JSON response data
* Display useful information from the response
* Handle errors using `try-except`

## How to Run

Install the required library:

```bash
pip install requests
```

Run the Python program:

```bash
python api_json.py
```
